# /conv — 對話歸檔與載入

同一個指令依檔案是否存在自動切換：不存在 → 保存；存在 → 載入。

## 參數

- 主題關鍵字（英文小寫、底線連接），例 `math1`、`arch_design`、`perf_tuning`。
- 未提供時，從對話內容取一個簡短英文關鍵字。

## 執行步驟

1. 確認 `.agent/conv/` 存在，不存在就建立。
2. 檔名：`.agent/conv/conv_<主題>.md`。

### 模式 A：檔案不存在 → 保存本次討論

整理：討論主題與背景、關鍵結論與決策、重要技術細節、後續行動，寫入：

```markdown
# <主題標題>

> <一句話摘要>
> 記錄日期：YYYY-MM-DD

---

## 一、背景與問題
- <討論的起因或問題>

## 二、關鍵結論
- <重點歸納>

## 三、技術細節
<視需要放程式片段、架構說明、比較表>

## 四、後續行動
- [ ] <待辦（如有）>
```

完成後告知用戶檔案路徑與摘要。

### 模式 B：檔案已存在 → 載入並接續

1. 讀取該檔完整內容。
2. 摘要：主題、關鍵結論、待辦。
3. 詢問要接續哪個部分，或有什麼新進展要補充；之後在同一檔追加新結論。

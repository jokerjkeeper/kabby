鍵盤快捷鍵

Ctrl+Shift+←/→切換 tab
Ctrl+Shift+D左右分割焦點 pane（同 tab 內並排）→ 出現空 pane，點 sidebar 填入不同 project 的 cc
Ctrl+Shift+E上下分割焦點 pane（同 tab 內上下疊），每 tab 最多 4 個 pane
Ctrl+Shift+W關閉焦點 pane（或點 pane 右上 ×，PTY 不殺）
Ctrl+Shift+B收合 / 展開左側欄（或點左上 ≡）
Ctrl+Shift+V按住說話錄音，放開後把文字打進焦點終端（同狀態列 🎙 說話鈕；不會自動按 Enter）
點擊 pane切換鍵盤焦點到該 pane（青色框標示）
拖曳分隔線調整兩 pane 比例；雙擊分隔線還原 50/50
Ctrl+L送給 cc 重繪畫面（多 client size 不同造成 TUI 殘留時用）
中鍵點 tab關閉 tab（全部 pane detach，PTY 不殺）
F1 或 ?開 / 關這個說明視窗
Esc關閉 modal（含本視窗）

畫面亂掉了？

多個 client（kabby Web UI + wepages iframe）視窗大小不一樣時，cc 的 TUI（選單、表單）對 size 變化的重繪不完美，可能殘留前一個尺寸的畫面。
▸ 點狀態列的 重繪 按鈕，或按 Ctrl+L，cc 會收到重繪訊號自動清整畫面。
